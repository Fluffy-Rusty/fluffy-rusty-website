# Fluffy Rusty — Cinematic Redesign

Sitio estático HTML/CSS/JS inspirado en el diseño de referencia proporcionado, adaptado a la identidad de Fluffy Rusty y a sus cuatro ilustraciones originales.

## Archivos
- `index.html` — contenido y secciones.
- `style.css` — diseño adaptable a escritorio y móvil.
- `script.js` — menú móvil, año del footer y botones de copiar.
- `assets/` — cuatro ilustraciones WebP.

## Publicar en Vercel
Sube estos archivos al repositorio conectado a Vercel, conservando la carpeta `assets/` en la raíz del proyecto. No requiere build command ni dependencias.

## Antes de anunciar el token
Sustituye `ADD_OFFICIAL_MINT_ADDRESS` por la dirección real y añade los enlaces oficiales de X, Telegram y DexScreener. No se muestran cifras de mercado inventadas.
